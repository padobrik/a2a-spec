# Sources

All snapshots are written by hand. No project code was run. The flow is the one in
`llama-index-core/tests/agent/workflow/test_multi_agent_workflow.py` (`test_workflow_execution`, lines 182-211, and `test_workflow_execution_empty`,
lines 215-231): the root agent `retriever` (FunctionAgent) hands off to `calculator`
(ReActAgent), which adds 5 and 3. Paths are relative to the repository root.

Events are written as their Pydantic dump. `ChatMessage` is
`{role, additional_kwargs, blocks}` (llama-index-core/llama_index/core/base/llms/types.py:1159-1164),
plus `content`, a computed property (:1201) that the consumers read as an attribute. A text
block is `{block_type: "text", text}` (types.py:249-253). `ToolOutput` is
`{blocks, tool_name, raw_input, raw_output, is_error}` plus the computed `content`
(llama-index-core/llama_index/core/tools/types.py:106-151). `AgentOutput.raw` is excluded
from the dump (workflow_events.py:77).
