agent-handshake checks that what your agent is told matches the tools it actually has.

**Status: pre-1.0, under construction.** The `handshake` command has no checks
yet, and none of 1.0 is released. The direction is described in
the [`1.0.0.dev0` section of the CHANGELOG](CHANGELOG.md).

Releases up to 0.10.0 on PyPI are a different, closed tool: contract tests
between agents. See [why it was closed](docs/history/contract-testing.md).
